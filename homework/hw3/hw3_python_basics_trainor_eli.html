Part 3 — Reflection

  • I knew that the longer the text is, the smaller the TTR would be, but it really surprised me to see just how small the Odyssy TTR calculated as with the whole text document!
  • Given how long the poem is, and how many occurences of character names there are, I don’t think getting rid of the Gutenberg license text wouold meaningfully change the TTR. It probably contains some unique words not in the rest of the poem, such as “Gutenberg” and “ebook”, but I don’t think it’s likely to make a huge change in either the token or type counts if it was excluded.
  • The dict structure felt the most efficient in the character-counting task because assigning the text.find index as the value did a lot of heavy lifting, and the printed result was easy to read. When doing the task on checking which character’s name appeared the most, I decided to do so by converting the dict to a complex list, then grabbing the character count integers in their own list, finding the max number of the list, indexing that max number, and finding the corresponding character and count within the complex list. There is a chance my method was more complicated than it needede to be, but working with (multiple) lists felt more difficult that working with one dictionary.
