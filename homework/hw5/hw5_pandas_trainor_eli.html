Creating the Dataframe

The following code is how I created a nested list and turned it into a dataframe.

rows = []
song_num = 0

for song in songs:
    song_num += 1
    lyrics = re.split(r"[\n]+", song)
    lyrics = [w for w in lyrics if w != ""]
    lyrics = [w for w in lyrics if not w.startswith("[")] # deleting all [Chorus], [Verse #], [Outro], etc.
    for w in lyrics:
        rows.append({"lyric": w, "track": song_num})

# saving as data frame
formentera_df = pd.DataFrame(rows)

The last collumn I added was a T/F based off if the idividual lyric had a content word of its song’s title. I used a website (commented below) to find the content words. An online friend helped me write this code and taught me that using .map allows you to use functions on every element of a dataframe.

title_content = ["doomscroller", "crashing", "feels", "eternity", "formentera", "enemies", "ocean", "settle", "false", "dichotomy", "paths", "sky"] # used https://app.readable.com/text/stopwords/

formentera2_df['contains_album_word'] = formentera2_df['lyric'].map(lambda x: any(keyword in x for keyword in title_content))

``` {python}
import re

print(formentera_text)

print(len(songs))
```

``` {python}
    song_rows.append({
```
