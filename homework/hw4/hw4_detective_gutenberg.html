Part 1 — Setup and Cleaning

Goal: download your two novels, strip off the Gutenberg header and footer from each, and end up with a clean list of lowercase words for each book.

  • Download both novels (Plain Text UTF-8) into ../../data/gutenberg/ — or wherever your hw4 folder expects them — with clear filenames.
  • Read each one in with .readlines(), inside a try/except so a bad filename doesn’t crash the whole document.
  • Use your while loops to chop the header off the front and the footer off the back of each book, the same way you did with Alice.
  • Glue the lines back together, lowercase, and split into words with re.split(), removing any empty strings left behind.

Explain what your cleaning code is doing, and disclose any AI use for this part.

Part 2 — Tokens, Types, and a Fair Comparison

Goal: compare the vocabulary richness of your two books, correctly.

  • For each book, report the total word count (tokens), the number of unique words (types), and the type–token ratio.
  • Compare the two raw TTRs — which book looks like it has the richer vocabulary?
  • Now compute the TTR of just the first 10,000 words of each book, and compare again. Explain, in your own words, why this second comparison is the fairer one.
  • Report the average word length for each book.

Explain your code for this part, and disclose any AI use.

Part 3 — Affixes, Dialogue, and Common Words

Goal: find measurable differences between your two authors’ styles.

  • Report each book’s rate of -ly words per 1,000 words, and look at the actual list — are they all adverbs, or does something else sneak in?
  • Pick three more affixes of your own choosing and report the per-1,000-word rate of each, for both books.
  • Using your header-free lines from Part 1, report what percentage of each book’s lines contain dialogue, however your book happens to mark it.
  • Report each book’s 10 most common content words (after removing stopwords), and say what they suggest about each book’s characters, setting, or themes.

Explain your code for this part, and disclose any AI use.

Part 4 — Visualize It

Goal: show your findings as charts.

  • Make one bar chart comparing your two authors on a single measure of your choice from Part 3.
  • Make one Zipf plot — rank vs. frequency, log scale on both axes — with both books on the same chart, each with its own label and a legend.
  • Every chart needs a title, axis labels, and should be saved to a file with plt.savefig().

Explain your code for this part, and disclose any AI use.

Part 5 — The Verdict

Below your code, write a short paragraph:

  • What makes each author’s style distinctive, based on what you measured?
  • Which measure was the most revealing? Which was the least useful?
  • If someone handed you an anonymous chapter, which single measure would you reach for first to guess the author, and why?

What you need to do How
Read a file line by line with open(path, encoding="utf-8") as f: lines = f.readlines()
Handle a bad filename without crashing try: ... except FileNotFoundError: ...
Chop lines off the front while a condition holds while not lines[0].startswith("..."): lines = lines[1:]
Chop lines off the back while a condition holds while not lines[-1].startswith("..."): lines = lines[:-1]
Glue a list of lines back into one string "".join(lines)
Split text into words, removing punctuation re.split(r"[\W]+", text.lower()), then drop empty strings
Count tokens / types / TTR len(words), len(set(words)), len(set(words)) / len(words)
Slice the first N items words[:10000]
Running total inside a loop total = 0 then total += len(w) for each w
Turn a count into a rate per 1,000 count / len(words) * 1000
Check the start/end of a string word.startswith("un"), word.endswith("ly")
Build a filtered list in one line [w for w in words if condition(w)]
Count and rank items Counter(words).most_common(n)
Bar chart plt.bar(labels, values)
Line chart with a log–log scale plt.plot(ranks, freqs) then plt.xscale("log"), plt.yscale("log")
Multiple lines on one chart with a legend plt.plot(x, y, label="...") for each, then plt.legend()
