Building New Lists

Cleaning Every Line?

  • We now know how to clean one line.
  • A for loop lets us clean every line:

try:
    with open("../../data/gutenberg/mansfield_park.txt", "r", encoding="utf-8") as f:
        book_lines = f.readlines()
except FileNotFoundError:
    print("Couldn't find that file — check the filename and location.")

for line in book_lines[100:105]:
    print(line.strip().lower())
  • But print() just displays the result – it doesn’t save it anywhere.
  • How do we end up with a new list of cleaned lines?

.append()

  • .append() adds an item to the end of a list:
terms = ["phoneme", "morpheme"]
terms.append("lexeme")
print(terms)
  • So we can start with an empty list and fill it up inside a loop.

Building a List with a Loop

messy = [" Phoneme\n", "MORPHEME ", "  syntax", "Semantics\n"]

clean = []                            # 1. start with an empty list
for term in messy:                    # 2. go through each item
    clean.append(term.strip().lower())   # 3. add the cleaned version

print(clean)

List Comprehensions

  • This pattern (empty list → loop → append) is so common that Python has a shortcut: the list comprehension
clean = [term.strip().lower() for term in messy]
  • Same result, one line, no .append().

Reading a List Comprehension

clean = [term.strip().lower() for term in messy]
  • Read it from the middle out:
    • for term in messy → go through each item in messy, calling it term
    • term.strip().lower() → what to do to each term
    • [ ... ] → collect all the results into a new list
  • General template: [ do something to item for item in some_list]

Loop vs. Comprehension

clean = []
for term in messy:
    clean.append(term.strip().lower())
clean = [term.strip().lower() for term in messy]
  • Same three parts: the source list, the loop variable, and what to do to each item.

Counters

  • In Linguistics, we often want to know how many words are in a text or how many sounds are in a word.

Counters

  • We could use the len() command:
items = ["color", "flavour", "theater", "center", "analyze", "organize", "favorite", "neighbor", "honor", "catalog", "honour", "flavor", "analyse", "flavor", "traveler"]
print(len(items))

Counters

  • Or we could create a counter, to count how many items there are:
items = ["color", "flavour", "theater", "center", "analyze", "organize", "favorite", "neighbor", "honor", "catalog", "honour", "flavor", "analyse", "flavor", "traveler"]

item_count = 0
for item in items:
    item_count += 1
    print(item, item_count)

Counters

  • We can do much more interesting things with counters, such as:
items = ["color", "flavour", "theater", "center", "analyze", "organize", "favorite", "neighbor", "honor", "catalog", "honour", "flavor", "analyse", "flavor", "traveler"]

c_item_count = 0
for item in items:
    if item[0] == "c":
        c_item_count += 1
        print(item, c_item_count)

  • Notice some inconsistencies in spellings?

.replace()

  • A method to replace one string with another.
word = "four"
new_word  = word.replace("our", "or")
print(new_word)

.replace()

  • Let’s broaden the scope so that it applies to all words ending in “-our”
items = ["color", "flavour", "theater", "center", "analyze", "organize", "favorite", "neighbor", "honor", "catalog", "honour", "flavor", "analyse", "flavor", "traveler"]

down_with_brits = []
for word in items:
    if word.endswith("our"):
        word = word.replace("our", "or")
    down_with_brits.append(word)

print(down_with_brits)
  • Note the .endswith() method - there’s also .startswith()

.split()

  • We can also take a line of text and split it up into a list.
getty = "Four score and seven years ago our fathers brought forth on this continent, a new nation, conceived in Liberty, and dedicated to the proposition that all men are created equal."

print(getty.split())
  • By default, split() separates according to whitespace.

.split()

  • But what happens if you do the following?
getty = "Four score and seven years ago our fathers brought forth on this continent, a new nation, conceived in Liberty, and dedicated to the proposition that all men are created equal."

getty_1 = getty.split(",")
getty_2 = getty.split(".")
getty_3 = getty.split("e")
print(getty_1, "\n", getty_2, "\n", getty_3)

re.split()

  • How would you split according to whitespace and punctuation?
  • Our old friend regex
import re

text = "Hello, world!   This... is a test."
words = re.split(r"[\W]+", text)
words = [w for w in words if w != ""]
print(words)

re.split()

import re

text = "Hello, world!   This... is a test."
words = re.split(r"[\W]+", text)
words = [w for w in words if w != ""]
print(words)
  • \W = non-word characters (punctuation, symbols, etc.)
  • + = one or more preceding
