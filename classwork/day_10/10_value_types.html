Translating grep into python

import re                                                     

with open("../../data/gutenberg/alice.txt", encoding="utf-8") as f:  
    text = f.read()

grep -Eo "c.t" alice.txt

matches = re.findall(r"c.t", text)   
print(len(matches))                  
print(*matches, sep="\n")

grep -Eo "c[aou]t" alice.txt

matches_aou = re.findall(r"c[aou]t", text)   # finds "cat", "cot", or "cut"
print(len(matches_aou))                      # counts how many were found
print(*matches_aou, sep="\n")                # prints each match on a separate line

More on Variables

True Variables vs. Constants

  • Most of what we call “variables” are true variables: values we expect to change or be reassigned (like my_age, current_year, child_18_year)
    • Written in lowercase snake_case

True Variables vs. Constants

  • A constant is a value meant to stay fixed for the whole program (like MAX_AGE = 100)
    • Python doesn’t actually enforce this — nothing stops you from reassigning it
    • Writing it in ALL_CAPS is a convention that signals to anyone reading the code: “don’t reassign me”

Number Operators: Exponent

Operators:

  • x ** y (exponent)
2 ** 2 == 2 * 2

Number Operators: Modulus

  • x % y (modulus: remainder)
10 % 3 == 1   # 3 goes into 10 three times, remainder 1
14 % 5 == 4   # 5 goes into 14 twice, remainder 4

Number Operators: Modulus

  • The modulus command is actually quite useful, as it shows us when one number is not evenly divisible by another.
n = 17
if n % 2 == 0:
    print("even")
else:
    print("odd")

Number Operators: Floor Division

  • x // y (floor division)
10 // 3   # 3  (3 goes into 10 three times, remainder dropped)
14 // 5   # 2  (5 goes into 14 two times, remainder dropped)
  • This is a way of rounding down, resulting in an integer
  • Note: there’s no built-in way to round up – you’ll have to do that in other ways

Summing up “Divisive” Operators:

14 / 5      # 2.8 (normal division)
14 % 5      # 4   (modulus)
14 // 5     # 2   (floor division)

Boolean (Logical) Values

Only two: True, False.

Usually created by comparisons:

first_name == "Bob"
# False

= vs. ==

Important!

  • = means variable assignment
  • == means equals or testing if two things are equal

Comparison Operators

  • == is exactly equal to
  • != is not equal to
  • > greater than
  • >= greater than or equal to
  • < less than
  • <= less than or equal to

Logical Operators

  • not flips a boolean
  • and is true if both are true
  • or is true if at least one is true

Examples

Check for Andrew with “w” or without:

(first_name == "Andrew") or (first_name == "Andre")

Examples

Check for Andrew, who is 47:

my_age = 47
(first_name == "Andrew") and (my_age == 47)

Examples

Check for Andrew, who is not 46:

(first_name == "Andrew") and not (my_age == 46)
